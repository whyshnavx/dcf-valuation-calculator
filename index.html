DCF Methodology

How the valuation engine works.

06

The model forecasts five years of Free Cash Flow and discounts those cash flows using the Weighted Average Cost of Capital. Terminal Value is calculated using the Gordon Growth Method.

FCF = EBIT × (1 − Tax Rate) − CapEx − Change in NWC
Terminal Value = FCF₅ × (1 + g) ÷ (WACC − g)
Enterprise Value = PV of Forecast FCF + PV of Terminal Value
Equity Value = Enterprise Value + Cash − Debt
Implied Share Price = Equity Value ÷ Shares Outstanding

DCF Methodology

Core formulas used by the valuation model.

06
EBIT
EBIT = EBITDA − D&A
NOPAT
NOPAT = EBIT × (1 − Tax Rate)
Free Cash Flow
FCF = NOPAT + D&A − CapEx − ΔNWC
Terminal Value
TV = FCFₙ₊₁ ÷ (WACC − g)
Enterprise Value
EV = PV of Forecast FCF + PV of TV
Equity Value
Equity Value = EV + Cash − Debt

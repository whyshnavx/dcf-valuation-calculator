# DCF Valuation Calculator

A financial valuation tool that estimates a company's intrinsic value using the Discounted Cash Flow (DCF) method.

## 📊 About the Project

This project was built to understand and apply fundamental corporate finance and valuation concepts used in investment banking and financial analysis.

The calculator projects a company's Free Cash Flow over a five-year forecast period and discounts those cash flows to their present value.

It then calculates:

- Enterprise Value
- Equity Value
- Terminal Value
- Present Value of Terminal Value
- Implied Share Price

## 🧮 DCF Methodology

The model follows the following valuation process:

Revenue  
↓  
EBITDA  
↓  
EBIT  
↓  
NOPAT  
↓  
Free Cash Flow  
↓  
Present Value of FCF  
↓  
Terminal Value  
↓  
Enterprise Value  
↓  
Equity Value  
↓  
Implied Share Price

## 📐 Key Formulas

### Free Cash Flow

FCF = EBIT × (1 − Tax Rate) − CapEx − Change in NWC

### Terminal Value

TV = FCF₍ₙ₊₁₎ / (WACC − Terminal Growth Rate)

### Enterprise Value

Enterprise Value = PV of Forecast FCF + PV of Terminal Value

### Equity Value

Equity Value = Enterprise Value + Cash − Debt

### Implied Share Price

Implied Share Price = Equity Value / Shares Outstanding

## 📥 Model Inputs

The calculator allows users to enter:
